01Overview

The problem, and the approach

Employees ask the same operational questions constantly: how much leave is left, where a payslip is, how to raise an IT ticket, what a policy actually says. Answering them across separate HR, IT, and knowledge systems is slow, and a naïve LLM will happily hallucinate a leave balance it has no business inventing.

The framework routes each message through a LangGraph orchestrator that classifies intent and dispatches it to specialized agents. Factual queries hit deterministic backend tools so numbers are never guessed; policy questions run through a hybrid RAG pipeline with evidence grounding and citations. It's built as a reusable framework, not a single bot: new domains sit on top of the same orchestration, retrieval, caching, and observability backbone.

03Engineering

What makes it hold up in production

Multi-intent orchestration

A LangGraph orchestrator classifies intent and routes to HR, IT, or Policy agents, with an aggregator that handles messages spanning multiple intents and a summarizer that keeps long conversations inside the context window.

Hybrid RAG with grounding

Policy answers fuse vector similarity with keyword retrieval, then pass an evidence evaluator and query rewriter before generation. Table-aware PDF parsing enables numeric analytics over policy documents, including currency, ranges, and comma-formatted values.

No hallucinated facts

HR and IT queries call deterministic backend tools, and the LLM only synthesizes around verified data, so a leave balance or ticket status is read from the system of record, never invented.

Semantic caching & resilience

A Redis semantic cache recognizes near-duplicate questions and shares answers across an organization, cutting latency and LLM cost. Per-employee rate limiting and circuit breakers protect the backend from downstream failures.

Observability as a first-class concern

Prometheus metrics and Grafana dashboards track latency, routing, RAG runs, and cache events; LangSmith traces every graph execution; and gzip-compressed JSONL audit logs capture each exchange with a propagated request ID.

Cloud-agnostic & pluggable

LLM provider, vector store, storage, and secrets manager all sit behind swappable factories, so the platform moves clouds with configuration, not rewrites. Delivered on Azure, with AWS support in progress as ongoing work.

05Impact

What it changed for employees

One assistant instead of three systems

HR, IT, and policy questions that used to mean checking three separate tools now resolve in one conversation, with tool calls doing the lookups so numbers like leave balances are never guessed.

Built to be watched in production, not just demoed

Prometheus, Grafana, and LangSmith tracing shipped with v1, not bolted on after, so accuracy and latency regressions get caught before employees notice them.
