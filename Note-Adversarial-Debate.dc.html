Why AIRP uses adversarial debate instead of a single LLM judge

A Contrarian agent that attacks the consensus, and why that produces a more trustworthy verdict than asking one model to grade its own reasoning.

Ask a single LLM "should I invest in this company?" and you get one confident answer with nothing behind it to scrutinize. Nobody checked its work. In AIRP, that's not how the verdict gets built. Four research agents produce a first pass, but before anything reaches a decision, a fifth agent's entire job is to attack it.

The setup

The Contrarian Investor agent reads every prior output in the shared state (fundamental, technical, sentiment, macro, and risk) and produces a structured report: a list of counter-arguments, the single strongest one the Portfolio Manager has to address, and a bear_conviction score from 1-10 representing how wrong the consensus might be.

It runs as a two-stage pipeline. Stage one builds counter-arguments deterministically, straight from the structured data the research agents already produced, no LLM call yet. Stage two hands that to an LLM to write the narrative and surface overlooked risks the deterministic pass wouldn't catch. The ordering is the point: the counter-argument list is populated before the model ever runs, so if the LLM call fails, the pipeline still has something real to work with instead of an empty report.

Why the conviction score isn't the LLM's call

bear_conviction is computed deterministically from the strength of the bullish signals versus the weight of the risk flags already in state. The LLM can write the argument, but it can't inflate or deflate the number that decides whether the committee argues again. That split exists on purpose: a model narrating "why this is risky" is doing something very different from a model self-grading "how risky is this, really," and conflating the two is exactly the failure mode a single-judge design has no way to catch.

The debate loop

When bear_conviction ≥ 7, the pipeline runs another round, capped at MAX_DEBATE_ROUNDS = 2 so a stubborn disagreement can't loop forever. The routing decision itself lives in a small, pure function evaluated only after that round's transcript has actually been appended to state, so there's never a round counted before it happened.

What the Portfolio Manager does with it

The verdict isn't just "here's what the Contrarian said." A high bear_conviction directly discounts the confidence score, and running two full debate rounds is treated as its own signal: a committee that argued twice and still couldn't agree is a different verdict than one that agreed instantly. The final memo includes human-readable debate highlights pulled straight from the transcript, so the disagreement is visible, not just factored in silently.

The trade-off

This costs latency. Every debate round is another set of LLM calls in the critical path, and AIRP's whole pitch is a memo in under 90 seconds. But a fast verdict that a real investment committee would have shredded on sight isn't actually useful. It's just confident-sounding. The debate loop is the part of the system that makes the 90-second number honest.
