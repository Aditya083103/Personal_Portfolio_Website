01Overview

The problem, and the approach

Ask a single AI model "should I invest in this company?" and you get one confident answer with no scrutiny behind it. Real investment decisions don't work that way. They come from a committee where specialists analyse, disagree, and a devil's advocate pokes holes before anyone commits.

AIRP models exactly that. An orchestrator plans the query and fans out to four research agents in parallel (fundamental, technical, news-sentiment, and macro), each grounded in real sources through retrieval. A structured two-round debate follows, where a Contrarian Investor attacks the consensus. A Risk Officer flags red flags and a Valuation Agent runs a DCF, then a Portfolio Manager weighs the full transcript and issues a Buy / Hold / Sell verdict with a conviction score and price target. The whole run streams live and finishes in under 90 seconds.

That core loop is now wrapped in a real product, not a demo script. Every user gets an account and a private dashboard of past analyses, can drop two tickers into a Compare mode that runs both committees at once and highlights the better metric, and can attach a company's annual report or earnings transcript so the committee reads it before debating. A verdict accuracy tracker then scores every past call against what the stock actually did, and a floating AIRP Assistant lets you interrogate any memo — or your whole history — in plain English, without ever being talked into issuing a new verdict.

05What I built

Engineering highlights

Parallel agent orchestration

A LangGraph state machine fans out to four research agents concurrently and reconciles their outputs through a shared typed state, persisted after every node, so a mid-run failure resumes instead of restarting.

Adversarial debate loop

A structured two-round debate where analysts respond to each other and a Contrarian Investor attacks the consensus, surfacing counter-arguments a single-pass model would never raise on itself.

Grounded RAG + valuation

A ChromaDB retrieval layer grounds every analyst in real sources — including any annual report a user uploads — and a Valuation Agent runs a DCF and peer comparison, so the final verdict rests on cited evidence and numbers, not model intuition.

Live streaming + observability

Agents stream progress to a React + TypeScript dashboard over WebSocket — including a live ReactFlow view of the LangGraph state machine as it executes — and every call is traced in LangSmith for latency, token usage, and prompt-version visibility.

Verdict accuracy tracker

A scheduled job scores every past BUY/HOLD/SELL against real market movement over a horizon-appropriate window using a dead-zone directional rule, and publishes the running score at /accuracy — the system grading its own track record instead of asking you to trust it.

Guardrailed conversational assistant

The AIRP Assistant answers questions grounded in a specific memo or a user's full analysis history, but is explicitly constrained so it explains a verdict already reached and can never be prompted into issuing, revising, or overriding one.

Concurrent compare mode

Two full committee runs execute concurrently for a head-to-head comparison, then every shared metric across both memos is diffed and the stronger value highlighted automatically.

Real multi-user product

JWT auth with registration, login, and a forgot/reset-password flow backs a per-user dashboard of analysis history — turning a research script into something other people can actually sign up and use, deployed live at zero infra cost.

06Impact

What shipping this proved

An auditable verdict, not a black box

Every Buy/Hold/Sell comes with the full debate trail and cited sources behind it, and the accuracy tracker keeps score against reality afterward: the transparency a real research desk would demand before trusting an AI call, not just a confident-sounding answer.

Multi-agent orchestration at production quality

Streaming a live 8-agent debate over WebSocket, with typed state and full LangSmith tracing, is the kind of system design that's hard to fake in an interview. It's proven end to end here.

A demo script became a product people can use

Accounts, a dashboard, compare mode, document upload, and a guardrailed chat layer are the unglamorous 80% of shipping AI software — all built and deployed live, solo, on a 100% free-tier stack.
